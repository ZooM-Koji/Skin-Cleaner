# Дневник кожи

Личное веб-приложение (PWA) для отслеживания лечения акне: ежедневный чек-ин, фото-дневник, курс Клензита, список средств с бюджетом, подсказки на простых правилах, графики и недельный отчёт текстом.

Приложение не заменяет врача. Подсказки — не диагноз и не назначение.

## Приватность

- Нет бэкенда, аккаунтов, аналитики и внешних запросов.
- Все данные, включая фото, лежат в IndexedDB браузера на вашем устройстве.
- На телефоне и на ПК данные разные и между собой не синхронизируются. Перенести их можно через экспорт и импорт JSON.
- Если очистить данные сайта или удалить приложение, записи пропадут. Делайте бэкап: «Ещё» → «Данные» → «Экспорт в JSON».

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

Сборка и локальный просмотр собранной версии:

```bash
npm run build
```

```bash
npm run preview
```

Тесты правил, дат и отчёта:

```bash
npm test
```

## Публикация на GitHub Pages

Для установки на телефон нужен адрес с HTTPS. В репозитории уже есть workflow `.github/workflows/deploy.yml`: он собирает приложение и публикует его при каждом пуше в ветку `main`.

1. Слейте код в ветку `main`.
2. В репозитории откройте Settings → Pages и в поле Source выберите **GitHub Actions**.
3. Дождитесь зелёной галочки во вкладке Actions. Адрес будет вида `https://<логин>.github.io/<имя-репозитория>/`.

Для приватного репозитория GitHub Pages доступен только на платном плане. Страница на Pages публична, но на ней только код: ваши записи и фото на сервер не попадают.

Сборка использует относительные пути, поэтому папку `dist` можно выложить и на любой другой статический хостинг (Netlify, Cloudflare Pages) без правок.

## Установка на телефон

**Android (Chrome):** откройте адрес приложения → меню ⋮ → «Добавить на главный экран» или «Установить приложение».

**iPhone (Safari):** откройте адрес именно в Safari → кнопка «Поделиться» → «На экран „Домой“».

**ПК (Chrome, Edge):** значок установки в правой части адресной строки.

После первого открытия приложение работает без интернета. Обновления подтягиваются сами при следующем запуске с сетью.

На iPhone Safari может удалить данные сайта, которым не пользовались несколько недель. Приложение, добавленное на экран «Домой», под это правило не попадает, но бэкап всё равно полезен.

## Как пользоваться

- **Сегодня** — чек-ин за день. Сохраняется сам при каждом нажатии. Стрелками можно перейти к прошлым дням.
- **Фото** — три ракурса на дату и сравнение двух дат. Фото сжимаются до 1600 px по длинной стороне.
- **Динамика** — воспаления, жжение и шелушение, частота нанесений, сопоставление триггеров.
- **Курс** — дата старта, номер недели, контрольная точка, фазы и периоды плановой частоты.
- **Ещё** — средства и бюджет, недельный отчёт с кнопкой «Скопировать», шаги ухода, экспорт и импорт.

Недели курса считаются от даты старта: день старта — первая неделя. Все даты считаются по московскому времени.

## Подсказки

| Условие | Что предлагается |
|---|---|
| Жжение 6 и выше два дня подряд | пауза или нанесение через день |
| Шелушение 7 и выше | вернуться на 4–5 раз в неделю |
| Активному средству в схеме меньше 10 дней | не вводить новый актив |
| Нет фото 14 дней | напоминание о съёмке |
| Отмечены болезненные узлы или кисты (за 7 дней) | показаться дерматологу |
| Краснота носа отмечается подряд дольше 3 недель | показаться дерматологу |
| Наступила контрольная неделя курса | сравнить фото и собрать отчёт |

Правила лежат в `src/lib/rules.ts`, тесты к ним — в `src/lib/lib.test.ts`.

## Устройство

React + Vite + TypeScript. Зависимостей в рантайме три: `react`, `react-dom` и `idb` (тонкая обёртка над IndexedDB). Офлайн-режим и манифест делает `vite-plugin-pwa`. Графики нарисованы своим SVG-компонентом, без библиотеки.

```
src/
  types.ts        модели данных
  seed.ts         начальные данные: курс, периоды, средства, шаги ухода
  db.ts           IndexedDB: чек-ины, фото, средства, настройки
  store.tsx       состояние приложения
  lib/            dates, rules, stats, report, backup, image
  components/     Chart, общие элементы интерфейса
  pages/          Today, Photos, Analytics, Course, More
```

Начальные данные записываются один раз, при первом запуске. Чтобы начать заново, очистите данные сайта в настройках браузера.
